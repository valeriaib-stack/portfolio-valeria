05.

Caso de estudio · SpringEduManager

El proyecto

Desarrollo de una aplicación web orientada a la gestión de información de alumnos utilizando Java y el ecosistema Spring.

El desafío

Avanzar desde ejercicios individuales de programación hacia una aplicación estructurada, comprendiendo cómo interactúan los distintos componentes de Spring Boot.

El proceso y la solución

Organicé el desarrollo progresivamente, implementando los componentes requeridos, controladores, rutas, persistencia y seguridad, realizando pruebas durante cada etapa del proyecto.

Herramientas

Java, Spring Boot, Spring MVC, JPA, MySQL, Thymeleaf, Spring Security, BCrypt, Eclipse y Postman.

Aprendizajes

El proyecto me permitió comprender con mayor profundidad la arquitectura MVC, persistencia de datos, controladores REST, seguridad mediante roles y la importancia de probar cada funcionalidad durante el desarrollo.

Resultado

Logré avanzar desde ejercicios básicos de Java hacia una aplicación web estructurada, integrando en un único proyecto diferentes conocimientos adquiridos durante el bootcamp.

¿Por qué este proyecto?

Elegí SpringEduManager porque representa uno de los desafíos técnicos más completos de mi formación y refleja mi evolución durante el proceso de aprendizaje Full Stack.
