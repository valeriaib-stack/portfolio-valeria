Caso de estudio · SpringEduManager

Descripción de la actividad

Desarrollo de una aplicación utilizando Java y Spring Boot orientada a la gestión de información de alumnos y a la aplicación práctica de conceptos de desarrollo backend.

Desafío principal

El principal desafío fue avanzar desde ejercicios individuales de programación hacia una aplicación estructurada con Spring Boot, comprendiendo cómo interactúan sus distintos componentes y cómo organizar las funcionalidades requeridas.

Solución propuesta

Organicé el desarrollo de forma progresiva, implementando los componentes requeridos, creando controladores y rutas para gestionar la información y realizando pruebas a medida que avanzaba en cada funcionalidad.

Herramientas técnicas utilizadas

Java, Spring Boot, Eclipse y servicios REST.

Principales aprendizajes

Este proyecto me permitió comprender con mayor profundidad la estructura de una aplicación Spring Boot, el funcionamiento de controladores REST, el manejo de rutas y la importancia de probar las funcionalidades progresivamente durante el desarrollo.

Resultado e impacto

Logré avanzar desde ejercicios básicos de Java hacia el desarrollo de una aplicación backend estructurada, integrando distintos conocimientos adquiridos durante el bootcamp en un mismo proyecto.

Habilidades técnicas aplicadas

Java, Spring Boot, programación orientada a objetos, servicios REST, organización de código, pruebas y resolución de problemas.

¿Por qué elegí este proyecto?

Elegí SpringEduManager porque representa uno de los desafíos técnicos más completos de mi proceso de formación. Este proyecto refleja mi evolución durante el bootcamp, ya que requirió integrar conocimientos anteriores, comprender nuevas herramientas y resolver dificultades durante el desarrollo.
